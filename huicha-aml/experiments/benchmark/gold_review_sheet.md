# 金标独立复核表（盲评）

请只根据告警类型、摘要样例、关键/干扰叙事项，给出三档之一：`exclude` / `observe` / `suggest_report`。
**不要**查看 `gold`、prompt 正文或跑分。填入 `gold_review_labels.json` 后运行 `score_gold_review.py`。

口径：排除 = 来源与去向均可闭合；观察 = 无异常节奏但缺关键材料；上报 = 有异常节奏或对手/陈述已被事实否定，且无经营生活解释。
