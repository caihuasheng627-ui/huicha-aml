# 循证慧查 路演 6 分钟

开场桥（30 秒）：洗钱赃款多来自诈骗/赌博；**调查提效 = 更快上报与追赃窗口**。上游检测已完成，本台只出草稿。

1. 点 **案例 A 排除**再重跑：指「判断来源对照」和「证据约束的 AI Judge」；说明规则对照与 AI 都排除，但两者没有加权。
2. 点 **案例 C 归集**或 **案例 L 多层**重跑：AI Judge 建议上报，而规则对照分别是观察/排除。展开支持、反向、缺失证据和关键证据反事实，说明 AI 在做综合研判。
3. 点 **案例 B 拆分** → 重跑建议上报；报告下出现 **待补证**（对手方 KYC / 资金用途等）。勾选后点 **写入草稿备注**，调查员意见框出现【补证清单】。系统不自动报送。**案例 C 归集**；**案例 L 多层**。
4. 点 **案例 F 观察**：退休 → **继续观察**。
5. 实验模式下打开 **幻觉演示** 重跑：`6222-FAKE-9999` 标红，不可签发。
6. 打开实验模式关闭 AI Judge 重跑，展示降级后只剩规则对照和模板骨架；不要声称规则基线更准或 AI 更准。
7. 指底部精标数 / 采纳率。实验口播：**虚构账号可拦截；Judge 与规则对照存在分歧；逐条引用契约和反事实流程可运行**（模板+stub，见 RESULTS.md）。
8. 导出底稿：须登录；非报送报文、须人签。导出人写入审计。
9. 点 **案例 H 抽数**（快捷键 `6`）：Collector 步骤应显示「窗口内约 150 笔，进模 ≤30 笔」；Judge 引用的是嵌入的贴线现金（`TX-H-CASH-*`）和夜间转出，而不是最早一批 POS。说明基线合计来自窗口全量，模型只看代表样本。
10. 指调查步骤里的 **Privacy** 和顶栏「进模脱敏」标签：工作台仍显示客户真名，但进模上下文是 `CLIENT_` / `ACCOUNT_` / `CUST_` 占位符；出站检漏失败会中止。强调这是竞赛原型脱敏，不是银行级加密。

快捷键：`1` `2` `3` `4` `5` `6` = **打开** A/B/C/F/L/H（不重跑）。改种子后请删 `backend/huicha.db` 再启后端。
一键 Demo：`cd backend && python -m app.demo`。
