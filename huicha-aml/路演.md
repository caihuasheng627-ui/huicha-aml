# 慧查 AML 路演 6 分钟

开场桥（30 秒）：洗钱赃款多来自诈骗/赌博；**调查提效 = 更快上报与追赃窗口**。上游检测已完成，本台只出草稿。

1. 点 **案例 A 排除**（打开历史）再点 **按当前策略重跑**：批发企业 + AI反向质询 ON → **排除**。指「可解释风险评分」与「AI反向质询」面板。
2. 打开 **实验模式**，关掉 AI反向质询，再重跑 A：同一案变 **建议上报**（消融）。顶部开关不会改写未重跑的历史草稿。
3. 点 **案例 B 拆分** → 重跑建议上报；**案例 C 归集**；**案例 L 多层**。
4. 点 **案例 F 观察**：退休 → **继续观察**。
5. 实验模式下打开 **幻觉演示** 重跑：`6222-FAKE-9999` 标红，不可签发。
6. 指底部精标数 / 采纳率。实验口播：**回查拦截毒化账号；关掉质询后批发类误报上升**（模板+stub，见 RESULTS.md）。
7. 导出底稿：非报送报文、须人签。

快捷键：`1` `2` `3` `4` `5` = **打开** A/B/C/F/L（不重跑）。改种子后请删 `backend/huicha.db` 再启后端。
一键 Demo：`cd backend && python -m app.demo`。
