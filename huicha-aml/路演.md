# 循证慧查 路演 6 分钟

开场桥（30 秒）：洗钱赃款多来自诈骗/赌博；**调查提效 = 更快上报与追赃窗口**。上游检测已完成，本台只出草稿。

1. 点 **案例 A 排除**（打开历史）再点 **按当前策略重跑**：批发企业 + AI反向质询 ON → **排除**。指「可解释风险评分」与「AI反向质询」面板。
2. 打开 **实验模式**，关掉 AI反向质询，再重跑 A：同一案变 **建议上报**（消融）。顶部开关不会改写未重跑的历史草稿。
3. 点 **案例 B 拆分** → 重跑建议上报；报告下出现 **待补证**（对手方 KYC / 资金用途等）。勾选后点 **写入草稿备注**，调查员意见框出现【补证清单】。系统不自动报送。**案例 C 归集**；**案例 L 多层**。
4. 点 **案例 F 观察**：退休 → **继续观察**。
5. 实验模式下打开 **幻觉演示** 重跑：`6222-FAKE-9999` 标红，不可签发。
6. 指底部精标数 / 采纳率。实验口播：**回查拦截毒化账号；关掉质询后批发类误报上升**（模板+stub，见 RESULTS.md）。
7. 导出底稿：非报送报文、须人签。

快捷键：`1` `2` `3` `4` `5` = **打开** A/B/C/F/L（不重跑）。改种子后请删 `backend/huicha.db` 再启后端。
一键 Demo：`cd backend && python -m app.demo`。

8. **反事实**：报告旁勾选 1–2 个风险因子或 Challenger Δ，看「若无此疑点」分档变化（不改正式结论）。
9. 顶栏徽章区分 **机制演示模式（LLM Stub）** 与 **百炼/线上模型**。右侧 **巡审时间线** 可见工具、校验与人签。
10. **质询对抗（30–60 秒）**：打开 **案例 B** 并生成草稿 → 调查区 **质询对抗演示集** → **一键演示**。16 条手写越权 Claim（越界 Δ、假证据、跨案、无谓词、幻觉账户等）全部走真实 Validator，应全部 **Reject** 并给出原因。这不是幻觉评测集。
