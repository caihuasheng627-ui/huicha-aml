# 慧查 AML 路演 5 分钟

1. 打开工作台，口播：**不是抓不到，是查不完。** 上游检测已完成，本系统只做调查草稿。
2. 点 **案例 A 排除**：批发企业 → **排除**。点报告里的 `TX-A-IN-01` 看证据跳转；右侧可看制度/类型学引用。
3. 关掉工具条 **质疑复核**，点 **按当前策略重跑**：同一案件变成 **建议上报**（消融）。再打开质疑复核跑回来。
4. 点 **案例 B 拆分**：拆分存入 + 夜间转出 → 建议上报。图谱里现金节点应显示「现金存入(N笔)」。
5. 打开 **幻觉演示** 再重跑：文中 `6222-FAKE-9999` 标红，**签发结论**不可用；此时「修改后采纳」须填写说明。
6. 点 **导出底稿**：下载 Markdown，强调非报送报文、须人签。

快捷键：`1` `2` `3` = 打开案例 A/B/C（不自动跑调查）；工具条按钮会直接跑调查。

补充：左侧可切「全部告警」看案例 D（退休大额，开质疑后预期 **排除**）与案例 E（餐饮夜间入账）。
